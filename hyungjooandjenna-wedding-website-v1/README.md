# Hyung Joo & Jenna Wedding Website

First draft for hyungjooandjenna.com

Wedding date: June 26, 2027
Venue: Jamsil Lotte World Korean Traditional Wedding Venue, Seoul

## Files
- index.html — main page
- style.css — design
- script.js — small interactive features

## How to preview
Double-click `index.html` on your computer.

## How to publish
1. Create a GitHub repository called `wedding-website`.
2. Upload these files.
3. Create a free Vercel account using GitHub.
4. Import the repository into Vercel.
5. Deploy.
6. After the design is approved, connect `hyungjooandjenna.com` in Vercel.
