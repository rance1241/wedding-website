# Hyung Joo & Jenna Wedding Website — Version 2.7

Version 2.7 simplifies dietary information.

## What changed
- Removed the dedicated dietary FAQ.
- RSVP now asks one simple open-ended question:

  **Do you have any dietary restrictions or food allergies?**

- Guests can provide whatever details are relevant.
- Removed the long list of specific dietary categories.
- Kept a separate optional notes question for anything else guests want to tell you.

## How to update the live site

Keep the existing Vercel Root Directory:
`hyungjooandjenna-wedding-website-v1`

1. Download and unzip Version 2.7.
2. Open GitHub → `wedding-website`.
3. Open `hyungjooandjenna-wedding-website-v1`.
4. Replace:
   - index.html
   - style.css
   - script.js
   - README.md
5. Keep/upload the `media` folder.
6. Commit changes.
7. Vercel redeploys automatically.
8. Refresh `https://www.hyungjooandjenna.com`.

Do not change Spaceship DNS or Vercel domain settings.
