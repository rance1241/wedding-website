- With the simpler, more playful title:
  - "Trailer"

Everything else from Version 2.9 remains unchanged.

## How to update the live site
1. Download and unzip Version 3.0.
2. Open GitHub → `wedding-website`.
3. Open `hyungjooandjenna-wedding-website-v1`.
4. Replace:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
5. Keep your existing `media` and `images` folders.
6. Commit changes.
7. Vercel redeploys automatically.
8. Refresh `https://www.hyungjooandjenna.com`.
